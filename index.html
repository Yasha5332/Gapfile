4 COST CONTROL LEVERS — each reduces cost per user → increases LTV
🗄️
Shared Cache
24–72h TTL across all users for same product. Popular products checked by many = near-zero marginal cost.
📉
Cap Review Count
Fetch latest 30–50 reviews per run instead of full history. Cuts Compute Unit cost significantly.
🔀
Smart Proxy Tier
Default: datacenter proxies. Escalate to residential proxies only when a page actively blocks.
⏱️
Run Timeouts
Hard timeout kills stuck jobs before they burn runaway compute. Test on 1–2 products first.

AI & TECHNICAL COMPETITIVE MOAT
🧠 Backend — AI Engine
Local LLM via Ollama (cost-efficient) + Claude API fallback. Handles local slang. Not just keyword matching — true sentiment categorization.
🎨 Frontend — Dashboard UX
Bento grid, glassmorphism, pill components. Built with Next.js + TypeScript + Tailwind V4. E-commerce merchants buy with their eyes — UI IS the moat.
🕷️ Data Layer — Apify
Custom Playwright Actor handles JS-rendered pages + anti-bot on Shopee/TikTok Shop. Proxy rotation, headless browser, cost-controlled via shared cache.
📡 Distribution — Zalo / Bot
Deliver insights via chat bots (Zalo, Telegram) where merchants already live. No app install friction. Meet users where they are.
